## 4. Technical Standards & Nominative Attribution

The Textbook and NetVision educational materials frequently reference open standards, RFCs (Request for Comments), and IEEE specifications to ensure real-world protocol accuracy.

### 4.1 Internet Engineering Task Force (IETF) Protocols
The following IETF RFC specifications are referenced strictly for nominative identification and educational analysis:
- **Core Transport & Framing**: RFC 768 (UDP), RFC 791 (IPv4), RFC 792 (ICMPv4), RFC 793 / RFC 9293 (TCP), RFC 826 (ARP), RFC 896 (Congestion Control / Nagle Algorithm), RFC 2018 (TCP SACK).
- **Naming & Addressing**: RFC 1034 / 1035 (DNS), RFC 1519 (CIDR), RFC 1918 (Private IPv4 Allocations), RFC 2131 (DHCP).
- **Routing Infrastructure**: RFC 2328 (OSPFv2), RFC 4271 (BGP-4).
- **IPv6 Architecture**: RFC 4861 / 4862 (NDP & SLAAC), RFC 4941 (IPv6 Privacy Extensions), RFC 5952 (Text Representation), RFC 8200 (IPv6 Specification).
- **Security & Modern Web**: RFC 3022 (Traditional NAT / PAT), RFC 8446 (TLS 1.3), RFC 9000 (QUIC), RFC 9110 (HTTP Semantics), RFC 9114 (HTTP/3).

*Note: All RFC documents are published by the Internet Engineering Task Force (IETF) and maintained by the IETF Trust. They are quoted and analyzed under fair use for technical standards instruction.*

### 4.2 IEEE 802 Standards
- **IEEE 802.3**: Ethernet Standards (10BASE-T through 400GBASE-R).
- **IEEE 802.1Q**: VLAN Tagging and Trunking Protocols.
- **IEEE 802.1D / 802.1w / 802.1s**: Spanning Tree Protocol (STP), Rapid STP (RSTP), and Multiple STP (MSTP).
- **IEEE 802.11a/b/g/n/ac/ax/be**: Wireless LAN Standards (Wi-Fi 4 through Wi-Fi 7).

*Note: IEEE standards are referenced strictly for nominative pedagogical comparison.*
